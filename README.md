# אתונה · הדר

לו״ז אינטראקטיבי לחופשה באתונה, 23–28 בספטמבר 2026.

הכניסה לאפליקציה נעולה בטביעת אצבע / Face ID (פעם ראשונה במכשיר — הרשמה, אחר כך פתיחה).

## הרצה מקומית

```bash
npm install
npm run dev
```

## פרטיות

הריפו ציבורי: מי שנכנס לקוד רואה את הלו״ז. הנעילה הביומטרית מגנה על פתיחת האפליקציה במכשיר, לא על הקוד בגיטהאב.
