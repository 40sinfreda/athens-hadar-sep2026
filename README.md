# אתונה · הדר

לו״ז אינטראקטיבי לחופשה באתונה, 23–28 בספטמבר 2026.

- ימים מלאים עם שעות, עלויות וקישורי Google Maps
- אטרקציות חלופיות לכל יום
- סימון שלבים שבוצעו (נשמר בדפדפן)

## הרצה מקומית

```bash
npm install
npm run dev
```

האפליקציה נפתחת ב־`http://localhost:8080`.

## הערה

הריפו פרטי כי הוא כולל פרטי הזמנה, דירה וטיסות.
